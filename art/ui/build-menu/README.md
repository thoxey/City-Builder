# Radial build-menu raster art

This directory contains immutable high-resolution masters, deterministic runtime derivatives, review proofs, and the machine-readable asset manifest for the radial build interface.

Production direction: exploration concept C — rough-edged rimless parchment medallion, broad joined silhouette, scratchy near-black contour, flat semantic spot colours, centred margin-safe composition, and no more than three comic emphasis marks.

The build-menu family uses a zoning-colour distinction in addition to the shared semantic palette: residential buildings are green (`#58705A`), commercial buildings are teal-blue (`#2E8290`), and industrial buildings are orange (`#C9743F`). Shape and ink remain the primary recognition cues.

All labels, prices, keys, and interaction text remain engine-rendered.

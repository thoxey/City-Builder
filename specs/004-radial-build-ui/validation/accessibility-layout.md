# Accessibility and layout

The approved 24/32/56/72 px, gameplay-background, grayscale, and contact-sheet
proofs were reviewed without regenerating artwork. Disabled state uses pattern,
lock, text, and color; focus uses an outline and fill. Labels expose tooltips and
accessible descriptions. The wheel clamps at viewport edges, the detail card
flips sides, status text compacts on narrow widths, and drawer-safe positioning
updates live. Acceptance images cover 1280×720, 1920×1080, edge origin, locked,
placement, blocked placement, demolition, drawer, and modal states.

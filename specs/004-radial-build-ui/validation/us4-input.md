# US4 input acceptance

Mouse uses polar hover/click; keyboard uses arrows or Q/E plus Enter/Escape;
gamepad uses the left stick, UI confirm/cancel, and Y to open. Returning the
stick to its dead zone preserves focus. Previous/Next paging never exceeds
eight wedges and reaches every item for 1, 8, 9, and 20-entry fixtures. Centre
activates Back at item level and Close at category level. Modal priority,
same-frame click consumption, invoking-control focus restoration, and the full
mode priority are implemented and covered by unit/integration checks.
